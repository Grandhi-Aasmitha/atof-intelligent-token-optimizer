## Structured contract
POST /v1/structured/optimize with X-ATOF-Structured: 1 on loopback. Supply task, kind, items (id, text, optional, score, superseded_by), authorized=true, and the relevant policy (allow_pruning or allow_deduplication). All units are required by default. Caller declares optionality and relevance; never infer authorization from task. History items must be complete turn groups. History removes explicitly superseded optional groups only, preserving latest and all referenced targets. Compaction is triggered by caller threshold; budget trimming preserves required units and may remain over budget. Memory threshold and retrieval top-k operate on supplied scores, not a vector database. Tool search uses lexical relevance, and tool schema, handoff and state projection use caller allowlists. Prompt dedup applies to explicitly optional exact duplicate template parts, not arbitrary natural-language rewrites. Embedding and duplicate-request dedup are within one explicitly authorized homogeneous batch, returning ID aliases for caller fan-out; duplicate requests must be idempotent. No cross-user or cross-request cache. Estimates count the prepared task/items only; alias map and report stay outside model input. Caller must actually use prepared input or unique jobs; no provider savings are verified.

GET /v1/features/readiness is the complete 48-entry inventory, with a concrete blocker for each unavailable capability. Existing /v1/features retains legacy text-engine semantics. POST /v1/verification/structured and python -m atof.verify_structured exercise 12 positive and OFF fixtures, no model calls. Run py -3.11 scripts/start_atof.py --verify --port 8081. Normal IDE integrations do not automatically supply structured bundles yet; this requires adapter work and matched validation. The remaining 22 features need implementation, not just a green status. Phase 10 acceptance remains open; do not declare Phase 11 production validation complete before these gaps are resolved.
