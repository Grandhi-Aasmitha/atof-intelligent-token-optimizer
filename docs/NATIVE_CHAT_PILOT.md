# Native Copilot chat pilot (0.9.3)
Install the latest VSIX and enable ATOF, trust the approved local workspace and enable the ATOF tool in normal Copilot Agent chat. No ATOF command is needed per request. Ask a read-only repository question, or ask about saved diagnostic files. The agent discovers paths through normal authorized search and may choose ATOF. Tool selection is not guaranteed. No implicit terminal history or unsaved buffers are read.
Optional prompt observation: in Copilot harness Customizations > Hooks, create a workspace or user userPromptSubmitted command hook pointing to the installed extension's native-hook.cjs using an approved absolute Node executable and script path. Review command before enabling; do not duplicate hooks. Hook requires Node and local port 8081. It sends only the submitted task to the local service for intent analysis; no raw task is stored by analytics. No hook rewrites prompts or approves tools. OFF suppresses hook observation and tool optimization. Hook discovery and payload support depend on IDE/harness and policy. No automatic hook installation or policy bypass.
Reports distinguish observed prompt, local candidate, client prepared tool output and unverified model consumption. Prompt observation and tool request IDs are separate; no session correlation is claimed. Native provider usage is not exposed by this path. Use ordinary authorized tools when no safe reduction exists.
